    Paritas: an Oracle-compatible PostgreSQL, built around one honest promise

    Published 22 Oct 2026 · Introductions

    Paritas is PostgreSQL 18 with an Oracle mode that runs real PL/SQL. It comes with one promise: we tell you exactly where compatibility ends for your code, with measured evidence.

    Every answer is compared with a real Oracle Database 21c, across 764 measured cases and 92,000 lines of real PL/SQL from nine schemas. On 15 October, answers matched Oracle in 78% of cases, against 67% for the open-source base. Real PL/SQL compiled unchanged in 57%, and the target for 1.0 is 90%. The list of known limitations runs past 200 entries, and most of them say what to do instead.

    Version 1.0 ships only when all eight published criteria hold, so it is not for sale yet. If you are planning a move off Oracle, we can show you the harness running live.
