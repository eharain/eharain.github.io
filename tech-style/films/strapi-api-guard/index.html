    Strapi API Guard Pro: records and fields, not just endpoints (early alpha)

    Published 19 Oct 2026 · Introductions

    Strapi permissions answer one question: can this role call this endpoint? Real systems also need to know which records and which fields each user may see.

    Strapi API Guard Pro checks every request twice. Before Strapi runs, it adds the filters a user is held to, and afterwards it strips the fields they should not see. It keeps each app's data apart, and it denies by default.

    It is in early alpha, version 0.0.1, under the AGPL. Follow it on GitHub.
