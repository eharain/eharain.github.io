    Same code, Oracle's answer: a Paritas server answers in Oracle mode only

    Published 19 Nov 2026 · Introductions

    Moving off Oracle, some of your code gives a different answer on PostgreSQL, with no error at all. A loop that walks backwards is silently skipped, and a query that mixes UNION and INTERSECT gains a row. Paritas gives Oracle's answer to both.

    Paritas is an Oracle-compatible database built on PostgreSQL. A Paritas server answers in Oracle mode only: every session reads Oracle's SQL. Your application keeps its code, and only the connection string and driver change.

    It is in development and not for sale yet. We are aiming to release it next quarter, and we can show you the test harness live.
