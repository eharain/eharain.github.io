    Two-Factor Auth Pro: a second factor for the Strapi admin panel

    Published 19 Oct 2026 · Introductions

    Strapi ships no second factor for its admin panel. Two-Factor Auth Pro adds one.

    After the password, the admin panel asks for a six-digit code from any authenticator app, and Strapi's own login still issues the session. Setup is a QR code and ten single-use recovery codes. Administrators can require it for everyone or per role, see who is actually protected, and end every other session with one button. A reset needs a code from the acting administrator's own authenticator.

    It works with Strapi v5, under the AGPL with a commercial licence available, and it is on npm.
