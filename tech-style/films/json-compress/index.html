    JSON Compress: lossless JSON compression that is still JSON

    Published 19 Oct 2026 · Introductions

    JSON Compress writes each key name once and turns lists of records into columns and rows. The result is still JSON, typically 45 to 75 percent smaller than minified, and it comes back byte for byte.

    Even with gzip on, it saves a further 5 to 20 percent. There are six implementations of one published format, in JavaScript, .NET, Go, Python, Rust and PHP, so you can compress in one language and restore in another. Five are on their registries, MIT licensed, with no dependencies.

    Try it in the browser on your own JSON. Nothing is uploaded.
