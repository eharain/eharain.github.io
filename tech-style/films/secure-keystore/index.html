    Secure Keystore: encrypted secrets at rest, with no service to run

    Published 19 Oct 2026 · Introductions

    Secure Keystore keeps secrets encrypted at rest with no service to run: a folder of encrypted values, and one user key that opens it.

    The user key is stretched with PBKDF2-SHA256 over 600,000 rounds. Every value then gets a key of its own through HKDF-SHA256 and is sealed with AES-256-GCM, with its name bound in. There are six implementations of one specification, in JavaScript, Go, .NET, Python, Rust and PHP, and each reads the stores the others write.

    Version 3.0.0, MIT licensed and OpenSource.
