    Moving an Oracle application to Paritas, step by step

    Published 20 Nov 2026 · Introductions

    How an Oracle application moves to Paritas, an Oracle-compatible database built on PostgreSQL, with its code left as it is. First, assess with pgrecon, which is available now: a read-only script your DBA runs, reporting each finding by object and line, with an estimate in person-days. Next, set up Paritas, which is in development: a server made in Oracle mode. Then bring the schema across as Oracle wrote it. In our gauntlet of real schemas, 137 of 253 package units that Oracle compiles also compiled unchanged on Paritas (16 October 2026). Load the rows with COPY, PostgreSQL's bulk loader; our migration tools are coming. Point the application at Paritas with a new connection string and a PostgreSQL driver for your language; Paritas drivers are coming. Last, run your own tests against Oracle and Paritas side by side, and switch over when the answers agree. Paritas is not for sale yet, and we are aiming to release it next quarter.
